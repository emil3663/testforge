# Test cases: CI command line (CI)

Section 3.10 of the [test plan](../../TEST_PLAN.md), which keeps the app overview, the feature status, the known limitations and the index of areas. Since TFP-253 each area's cases are in a file of their own; a ticket names the area it touches. Phase 47's cases (`docs/decisions/phase-47-ci-integration-decision-record.md`, Regression Policy); the command is `testforge run` (README, "Running TestForge in a pipeline").
