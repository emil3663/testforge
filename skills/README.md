# Skills

This directory holds Claude Code skills extracted from TestForge's own
testing judgment, starting with
[`write-playwright-test`](write-playwright-test/SKILL.md), which packages
the best-practice coverage reasoning from `src/lib/generate/prompt.ts` so
it can be used directly inside a coding agent's workflow without running
the TestForge app. It's the first of several skills planned for this
directory, not a rename of the product — see
[`docs/decisions/phase-17-skills-extraction-backlog.md`](../docs/decisions/phase-17-skills-extraction-backlog.md)
for the roadmap and the other candidate skills under consideration.
